# Vijay Raut Portfolio

A responsive, static portfolio website built with HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio page
- `style.css` — responsive styling
- `script.js` — mobile menu + current year
- `assets/profile.png` — profile photo
- `Vijay_Raut_Resume.pdf` — resume download

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Publish

### Option 1 — Netlify (fastest)
1. Open https://app.netlify.com/drop
2. Drag the whole `Vijay_Raut_Portfolio` folder into the Drop area.
3. Netlify will publish it and give you a `netlify.app` URL.
4. Use the site's project settings to customize the site name.

### Option 2 — GitHub Pages
1. Create a GitHub repository named `vijayraut00.github.io`.
2. Upload the contents of this folder to the repository root.
3. Enable GitHub Pages from the repository's Pages settings.
4. Your user site will use the `github.io` address for the account.

## Short link

After you have the final live URL, paste it into TinyURL and optionally choose a custom alias such as `vijay-portfolio` if available.

Important: a short-link service cannot be finalized until the destination URL exists.
